Configuração dos novos campos no Supabase

As contagens continuam usando a tabela existente. Para compartilhar os novos campos entre dispositivos, execute o SQL abaixo no SQL Editor do seu projeto Supabase e clique em “Tentar sincronizar”. Até lá, questionamentos e ajustes ficam salvos neste navegador, com aviso de sincronização pendente. O SQL não remove dados nem altera permissões.

Exibir SQL de configuração
ALTER TABLE public.contagens
  ADD COLUMN IF NOT EXISTS questionamento text DEFAULT '',
  ADD COLUMN IF NOT EXISTS ajustado boolean NOT NULL DEFAULT false;
NOTIFY pgrst, 'reload schema';

Fonte: base original de seis lojas, preservada integralmente. Diferença = contagem − saldo. “Só pendentes” exibe itens sem contagem. Impressão e CSV para contagem: descrição, GTIN, saldo e espaço em branco; respeitam a busca e “só pendentes”. Escolha uma loja ou todas. CSV completo mantém todos os registros e campos. Datas exibidas no horário local; o nome é mantido apenas no registro de auditoria existente, nunca na coluna de data.
